# 繁體中文模組

核心規則一到四照 `SKILL.md`。中文文件另外加下面兩條，以及一項額外檢查。

## 規則五：破折號插入句拆成獨立句子

`——` 把補充塞進句子中間，讀者得把主句記在腦裡、繞過補充、再接回來。中文尤其累。

一律拆成兩句。只有真的是語氣轉折時才留。

## 規則六：標點一律全形

中文句子裡的標點用全形。

| 符號 | 用哪個 |
|---|---|
| 逗號 | `，` U+FF0C |
| 冒號 | `：` U+FF1A |
| 分號 | `；` U+FF1B |
| 問號 | `？` U+FF1F |
| 句號 | `。` U+3002 |
| 括號 | 內含中文用 `（）`；純英數或程式碼用 `()`，前後加空格 |

不動的：程式碼區塊內、行內 `code`、`https://`、時間 `20:37`、小數點、版本號、檔名。

兩支腳本：

```bash
python3 ${CLAUDE_SKILL_DIR}/scripts/fix_punct.py   <檔案>   # 就地轉全形
python3 ${CLAUDE_SKILL_DIR}/scripts/check_punct.py <檔案>   # 驗證，0 處才會回傳 0
```

`fix_punct.py` 會保護程式碼區塊、行內 code、連結目標、URL 與時間，對已經改好的檔案是冪等的。
但它是機器判斷，跑完一定要用 `check_punct.py` 驗，並且自己看一眼 diff。

## 盤點理由時搜這些詞

流程第三步用：

```bash
grep -n "為什麼\|這是刻意的\|理由是\|以前是\|因為" <原文>
```
